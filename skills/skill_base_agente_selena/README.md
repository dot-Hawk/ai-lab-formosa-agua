# Skill personal de Selena Milagros Britez

Esta carpeta reúne el contexto individual que complementa el [protocolo general](../../SKILL_BASE.md). Para usarla en una sesión de Codex, pedí que lea directamente [SKILL.md](SKILL.md), el protocolo y la ficha. La detección automática desde `skills/` queda por verificar en el runtime del equipo.

| Archivo | Contenido |
|---|---|
| [SKILL.md](SKILL.md) | Instrucciones operativas para la rama personal |
| [perfil.yaml](perfil.yaml) | Identidad, referencias Git, alcance y comandos verificados en main |
| [MATRIZ_COMPATIBILIDAD.md](MATRIZ_COMPATIBILIDAD.md) | Correspondencia con el protocolo, pendientes y registro del alta |

El equipo debe confirmar los datos del registro individual, los IDs, el runtime habitual y sus subagentes, las asignaciones, las tareas y dependencias, el canal de estado, los revisores y la estrategia de integración. Los comandos marcados como pendientes carecen de una entrada verificada para ese uso en la base consultada.

Ante una actualización del protocolo, aplicá la comparación indicada en SKILL.md y ajustá la ficha y la matriz con el nuevo commit y la versión. Usá la VCPD y las [plantillas de coordinación](../../PLANTILLAS.md) para registrar la revisión.
